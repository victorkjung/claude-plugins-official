# PRD: Photo-First Maintenance Requests

_Fictional sample for testing doc-eval._

## Problem
Tenants submit maintenance requests by text and email with little detail. Technicians often arrive
without the right parts, so the job takes a second visit. We want the process to be better and faster.

## Goals
- Make it easy for tenants to submit requests
- Reduce repeat visits
- Improve tenant satisfaction

## Requirements
1. Tenants can submit a request from the tenant portal with a description and photos.
2. The system suggests a category (plumbing, electrical, appliance, other) from the photos and text.
3. Property managers see new requests in a queue and can assign a technician.
4. Tenants get status updates.
5. It should be fast and work well on mobile.

## Success metrics
- Fewer repeat visits
- Higher satisfaction scores

## Timeline
Design in October, build in November, launch before the holidays.

- Do we support video?
